# Política de seguridad

## Versiones soportadas

| Versión | Soporte |
| --- | --- |
| 19.0.1.2.x (actual) | Sí |
| anteriores | No |

## Reportar una vulnerabilidad

Por favor **no abras un issue público** para vulnerabilidades de seguridad.

1. Usá la pestaña **Security → Report a vulnerability** de este repositorio
   (reporte privado de GitHub), o
2. Contactá al maintainer por GitHub (@MrErov).

Incluí: versión del módulo, pasos de reproducción, impacto y, si podés, una
propuesta de mitigación. El objetivo es responder en un plazo de 7 días
hábiles y coordinar la divulgación una vez haya un fix disponible.

## Alcance

Aplica al código de `addons/l10n_ve_compliance_manager/`. Los datos fiscales
reales, credenciales de instancia y configuraciones locales (`odoo.conf`,
`.env`, `filestore/`) no forman parte de este repositorio.
